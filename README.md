# GaramGaram Food Delivery Site

GaramGaram is a responsive food delivery website built with HTML and CSS. It showcases food categories, offer banners, menu cards, an order form, and social links for a simple restaurant or delivery service landing page.

## Features

- Sticky navigation header
- Hero section with brand message
- Food category shortcuts
- Offer banner section
- Menu sections for biryani, non-veg, snacks, veg, desserts, and beverages
- Food cards with images, descriptions, prices, and order buttons
- Order form with customer details, dish selection, quantity, and instructions
- Contact section with social media links
- Responsive layout for mobile screens

## Tech Stack

- HTML5
- CSS3

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Sankha708/Food-Delivery-site.git
```

2. Open the project folder:

```bash
cd Food-Delivery-site
```

3. Open `index.html` in your browser.

## Notes

The order form is currently a static frontend form. To process orders, connect the form action to a backend service or form handling platform.
